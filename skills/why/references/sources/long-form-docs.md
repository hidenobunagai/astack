# Long-form documents (Notion, Confluence, Google Docs)

## What this source contains

- Data dictionaries and metric specs
- Analysis plans and design docs for a pipeline or model
- Findings reports and their methods sections
- Meeting notes from reviews of a metric or a model

## How to search it

1. **Search for the metric or table name** and the business term.
2. **Read the whole page.** The reason is often in an "alternatives" or "open questions" section.
3. **Follow child pages and linked docs** within this source only.
4. **Check the date and status.** Draft specs can describe a plan that changed.

## What good evidence looks like

- A metric spec with a "why this definition" section that names the rejected options.
- A findings report that states the method and the exclusions.

## Common pitfalls

- **Specs drift from code.** Note any difference between the doc and the code. The synthesizer will show it.
- **Unlinked docs.** The useful page may not link anywhere. Broad searches help.
- **Access limits.** If a page cannot be read, record it as a gap.

## What to return

- Title, URL, authors, and last-updated date
- The passage quoted verbatim, with its section
- Whether the doc is final or a draft
